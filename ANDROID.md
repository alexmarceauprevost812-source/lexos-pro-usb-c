# Version Android LexOS Textes

Les sources Android sont dans [android/](android/README.md).

La compilation de l’APK de test est disponible dans Actions → Construire APK Android. Télécharger l’artefact après une exécution réussie.

Cette première version est un éditeur hors ligne avec sauvegarde USB, brouillons et ouverture de textes. Le moteur d’IA reste à intégrer.
