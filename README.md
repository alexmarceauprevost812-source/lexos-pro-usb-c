# lexos-pro-usb-c

LexOS sur clé USB-C.

- [`usb/`](usb/README.md) — **LexOS IA** : plusieurs IA locales installées sur la clé, un clic pour les activer dans un terminal (Chat · Codex · CodexTerminal), icônes sur le bureau du PC.
- [`desktop/`](desktop/README.md) — LexOS Textes pour PC (Linux, Windows, macOS).
- [`android/`](android/README.md) — LexOS Textes pour Android.

Voir [VERSIONS.md](VERSIONS.md).
